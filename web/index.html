Mantle: make Claude yours

Mantle is a free, open-source Claude Code plugin. It puts one theme across Claude Code, Windows Terminal, iTerm2 and claude.ai, with 4K wallpapers and colors that react to what Claude is doing.

Mantle Atlas

A knowledge base of 30,000+ agent skills, 17,000+ MCP connectors and 440 plugins. Ask Claude "is there a skill for X" or "connect Claude to Jira" and it recommends the right tool with its install command, suggests tools for your project's stack, and checks third-party skills before you install them.

Mantle Doctor

A check-up for your Claude Code setup: context cost per session, CLAUDE.md rules that get ignored, MCP servers that fail on Windows, secrets in config, and permission rules.
